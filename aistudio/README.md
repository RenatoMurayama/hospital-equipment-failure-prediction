# Altair AI Studio process

Place the exported process file here: `FE02_Preparacao_Dados.rmp`.

To export it in AI Studio: open the process, then **File → Export Process...** and save it as `FE02_Preparacao_Dados.rmp`.

To reuse it: **File → Import Process...**, then point the two `Retrieve` operators to the imported `equipamentos` and `leituras` datasets.
